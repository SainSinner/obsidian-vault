### **Назначение**

1.        Представление детальных данных по сущностям логической модели данных. 

2.         

3.        Слой представляет данные для всей организации в целом, а не для специфичных задач или отчетов.

4.        Может использоваться: для отчетности, для  клонов,  для экспорта во вне через слой Export Marts.Каждая сущность должна быть отнесена к предметной области (список ниже под таблицей).
### **Ограничение**

1.        Детальные данные не должны агрегироваться, перемешиваться и вообще как-то изменяться относительно модели.

2.        Допускаются минимальные вычисления – арифметические действия, строковые операции, операции с датами или преобразования типов  - но строго с данными одной строки.

3.        Экспорт во внешние системы только через Export Marts.

4.        Слой нормализован. Модель звезда или снежинка.

5.        Наполняется только из слоя RAW.
