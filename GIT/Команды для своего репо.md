**git pull origin main**
Скачивает изменения и автоматически сливает их с вашей текущей веткой

**git pull --rebase origin main**
Заменяет все изменения удаленной веткой

**git status**
Проверяем статус репозитория

**git add .**
Добавляем все изменения

**git commit -m "some message"**
Комитим наши изменения в ветку с каким-нибудь сообщением

**git pull**
Отправляем изменения
