##### Как сцепить слить поганый KHD 2.0  тест с веткой

**Переключиться на свою ветку**
git checkout my-branch

**Подтянуть свежий test**
git fetch origin
git merge origin/test

**Сохранить и выйти из VIM где нужно написать комментарий к коммиту**
:wq

**Для всех конфликтов взять версию из test**
git checkout --theirs -- .
git add .
git commit -m "resolve conflicts: take theirs from test"
