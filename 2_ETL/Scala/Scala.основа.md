# Переменная

**Переменные в Scala бывают двух типов**: 

- **val** (неизменяемые переменные, т.е. значение этой переменной присваивается один раз и больше не меняется)
- **var** (изменяемые переменные, т.е. при необходимости можно изменить значение переменной)

**Создание переменной:**


# Типы в Scala

На предыдущем шаге мы работали с переменной типа `String`:

```scala
val aString: String = "Hello" // переменная типа String
```

`String` - не единственный тип, доступный для использования. В нашем распоряжении есть следующие базовые типы:

1. `Byte` (8 битовое знаковое значение. Диапазон от `-128` до `127` или от −27−27 до 27−127−1 включительно)
2. `Short` (16 битовое знаковое значение. Диапазон от -32768 to 32767  или от −215−215 до 215−1215−1 включительно)
3. `Int` (32 битовое знаковое значение. Диапазон от −231−231 до 231−1231−1 включительно)
4. `Long` (64 битовое знаковое значение. Диапазон от −263−263 до 263−1263−1 включительно)
5. `Float` (32 битовое IEEE 754 число с плавающей точкой одинарной точности )
6. `Double` (64 битовое IEEE 754 число с плавающей точкой двойной точности )
7. `Char` (16 битовый беззнаковый символ Unicode)
8. `String` (последовательность экземпляров `Char`)
9. `Boolean` (значение `true` или `false`)

Пример создания переменных базовых типов: 

```scala
  val aString  = "Hello"
  val aChar    = 'C'

  val aInt     = 11
  val aLong    = 11L
  val aFloat   = 2.0F
  val aDouble  = 2.0

  val aBoolean = true
```

Как видите, в приведенном примере мы не прописываем типы вручную, а предоставляем компилятору возможность самому автоматически определить типы переменных. При этом на конце у некоторых чисел дописаны буквы `L`, `F` (`val aLong = 11L`). Это сделано для того, чтобы подсказать компилятору, какой тип нужен. 

Если написать так:

```scala
  val aNumber       = 11 // тип Int
  val anotherNumber = 11 // тип Int
```

то обе переменные будут иметь тип `Int`, так как по умолчанию все целочисленные значения имеют тип `Int`. Чтобы переменной был назначен тип `Long`, потребуется дописать суффикс `L` или `l`:

```scala
  val anIntNumber = 11 // тип Int
  val aLongNumber = 11L // тип Long
  val anotherLongNumber = 11l // тип Long
```

Чтобы отличить `Float` от `Double` применяется суффикс `F` или `f`:

```scala
  val aFloat = 2.0F
  val anotherFloat = 2.0f

  val aDouble = 2.0
```

# Работа со строками

Для работы со строками существуют следующие полезные методы (более полный список методов по работе со строками можно найти [в документации](https://www.scala-lang.org/api/2.12.7/scala/collection/immutable/StringOps.html)) :

- `.length` - выводит длину строки
- `.charAt(index)` - возвращает символ строки, находящийся на указанной позиции (`index`) в строке. В качестве индекса допускается указывать значения от `0` до `length - 1`
- `.substring(beginIndex, endIndex)` - возвращает подстроку
- `.startsWith(prefix)` - проверяет, начинается ли строка с указанного префикса (`prefix`)
- `.replace(target, replacement)` - заменяет одну часть строки `(target)` на другую `(replacement)`
- `.toLowerCase` - все символы в строке преобразует в нижний регистр (все большие буквы превращает в маленькие)
- `.toUpperCase` - все символы в строке преобразует в верхний регистр
- `.reverse` - возвращает перевернутую строку
- `.take(n)` - возвращает строку, состоящую из `n` первых символов исходной строки; при этом метод `take` направлен на взятие первых `n` элементов, и задать отрицательное число для n не выйдет
- `.toInt` - преобразует значение `String` в значение типа `Int` (если преобразование невозможно, будет исключение `NumberFormatException`)

С работой методов можно ознакомиться, изучив следующий код: 

```scala
  val aString: String = "Hello, world!"

  println(aString.length) // выводит 13
  println(aString.charAt(1)) // выводит e
  println(aString.substring(0, 2)) // выводит He
  println(aString.startsWith("He")) // выводит true
  println(aString.replace("!", ".")) // выводит Hello, world.
  println(aString.toLowerCase) // выводит hello, world!
  println(aString.toUpperCase) // выводит HELLO, WORLD!
  println("abcd".reverse) // выводит dcba
  println("abcd".take(2)) // выводит ab


  val aStringNum: String = "123"
  val anIntNum: Int = aStringNum.toInt

  "df".toInt // преобразование "df" в число невозможно, будет NumberFormatException
```

Особое внимание обратите на работу методов `length`, `charAt` и `substring`. Крайне важно не запутаться в индексах:

# Интерполяция строк

Интерполяция применяется, когда в строку необходимо вставить значение переменной. 

Самым распространенным строковым интерполятором является `s`-интерполятор. Используется он следующим образом:

- перед строковыми кавычками `"` ставится `s`

- перед именем переменной ставится знак `$`

```scala
  val courseTitle = "Scala"
  println(s"Welcome to $courseTitle course") // Welcome to Scala course
```

Дополнительно стоит отметить следующее:

1 аналогичного результата можно достичь, если написать код так:

```go
  println("Welcome to " + courseTitle + " course") // Welcome to Scala course
```

2 если в строку вставляется значение выражения, то выражение заключается в скобки `{ }`:

```scala
println(s"Welcome to ${courseTitle.toUpperCase} course") // Welcome to SCALA course
```

3 чтобы было легче управлять выводом, существуют специальные символы:

- \n - означает переход на новую строку
- \t - создает отступ 

```scala
  println(s"Welcome to \n$courseTitle course")
  /*
  Welcome to 
  Scala course
  */


  println(s"Welcome to \t$courseTitle course")
  // Welcome to 	Scala course
```

 4 если требуется игнорировать обозначенные выше специальные символы, вместо `s` используется `raw`-интерполятор

```scala

println(s"Welcome to \t$courseTitle course")
// Welcome to 	Scala course

println(raw"Welcome to \t$courseTitle course")
// Welcome to \tScala course
```

# Выражения(Expressions) и Инструкции (Instructions)

Прежде всего отметим, что если _выражение_ - это когда мы возвращаем какое-то, как правило, вычисленное значение, то _инструкция_ - это когда мы выполняем какое-то действие, говорим компьютеру сделать что-то, но значение не возвращаем.

В Scala все является выражением. А у выражений есть два основных свойства:

1. имеют тип
2. возвращают какое-то значение

Поэтому, чтобы сделать код рабочим, не требуется обязательно присваивать выражение какой-либо переменной:

```scala
  // вариант написания кода № 1
  val aVal = 1 + 2 * 3
  print(aVal)



  // вариант написания кода № 2
  // обходимся без присваивания выражения переменной
  print(1 + 2 * 3)
```

**Примечание:**

1. `print` отличается от `println` тем, что если print выводит символы и не переходит на следующую строку, то `println` – напечатает символы и курсор перейдет на следующую строку
2. перечень основных операторов, которые применяются в выражениях: `+`, `-`, `/`, `*`,  `&`, `<<`, `>>`, `>>>`, `==`, `!=`, `>`, `>=`, `<=`, `<`, `!`, `&&`, `||` (с большинством этих операторов вы уже должны были встречаться в других языках, поэтому подробно останавливаться здесь на описании каждого оператора не будем; даже если есть что-то незнакомое, вы все узнаете в процессе дальнейшей работы, так что сейчас можно и не заучивать все и сразу)
3. методы отношений "боль­ше" (`>`), "меньше" (`<`), "больше или равно" (`>=`), "меньше или равно" (`<=`) выдают значение типа `Boolean`:  `val aVal: Boolean = 1 > 2`
4. инвертировать булево значение можно посредством `!`: 
    
    ```scala
      val aVal: Boolean = !false
      println(aVal) // true
    ```
    
5. все в Scala является выражением, и код с `if` не является исключением:
    
    ```scala
      val aCondition = true  
    
      // если сразу прописать if-выражение в print, это не будет ошибкой
      println(if(aCondition) "True Condition" else "False Condition") // выведет True Condition
    ```
    
    обратите внимание, что в Scala, в отличие от других языков программирования, мы не кодим в стиле:
    
    `if (условие):       присвой значение (пишем для этого инструкцию)   else:       присвой переменной другое значение (пишем еще одну инструкцию)`
    
    а сразу пишем значение, которое хотим присвоить в первом и во втором случае `if(_условие_) _присваиваемое_значение_1_  else _присваиваемое_значение_2_`
    
6. операторы на самом деле являются методами:

```scala
// вариант кода №1
  val aVal = 2 * 3 
  println(aVal) // 6


// вариант кода №2 - прописываем вызов метода *, 
// которому передаем 3 в качестве аргумента
  val aVal = 2.*(3)
  println(aVal) // 6
```
