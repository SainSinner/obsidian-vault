# Соответсвие MAC Windows
**Ctrl** = **Cmd**
**Alt** = **Option**
**Shift** = **Shift**
**Win** = **Command**

# DBeaver
Блоковое выделение
**Ctrl + Alt + A** + курсором выделить
Форматирование кода
**Ctrl + Shift + F**

# VSCode
Блоковое выделение
**Alt** + курсором выделить
Глобальный поиск
**Ctrl + Shift + F**
Форматирование кода
**Ctrl + F**
Uppercase
**Ctrl + Alt + U**
Lowercase
**Ctrl + Alt + U**
Show and Run Commands
**Ctrl + Shift + P**
